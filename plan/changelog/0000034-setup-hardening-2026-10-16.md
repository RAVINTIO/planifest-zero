**Feature:** Setup hardening
**Pipeline run:** P0 to P9 completed. No phases skipped.
**PR:** https://github.com/planifest/planifest-zero/pull/7

## What Was Built

Setup is now safe to re-run on a project that an older release installed. This release delivers five backlog items:

- **Retired flags (0000092):** `setup.sh` and `setup.ps1` accept four retired flags with one warning each, then continue. The flags are `--structured-telemetry-mcp`, `--backend-url`, `--context-mode-mcp`, and `--include-full-skill-library`. Setup skips the `--backend-url` value and never prints or stores it. A refresh of an older install now completes.
- **Exact tool name (0000088):** `setup.sh` matches the tool name exactly, the same as `setup.ps1`.
- **Atomic settings writes (0000091):** every `settings.json` write goes through `settings.json.planifest-tmp` in the same folder. The file is never left truncated, keeps its mode or ACL, and a planted link at the temporary path is never followed.
- **Missing node warning (0000091):** `setup.sh` warns when it skips the telemetry cleanup because `node` is missing.
- **Housekeeping (0000096, 0000102):** the stray root `.feature-id` is gone, and the backlog template allows `human request` as a deferral source.

## Decisions

- **ADR-001:** Retired setup flags warn and continue. This supersedes the no-op rejection in 0000030 ADR 001, because a warning keeps the signal that ADR wanted.
- **ADR-002 (v0.1.1):** `settings.json` writes go through a same-folder temporary file. P5 hardened the first version against a planted symlink, a mode reset, and a non-atomic Windows move.
- **ADR-003:** The stack stays as it is.
