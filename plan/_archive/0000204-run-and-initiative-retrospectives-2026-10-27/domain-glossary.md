# Domain Glossary - run and initiative retrospectives

**Skill:** [plan](../skills/ravintio-plan/SKILL.md)
**Feature:** 0000204-run-and-initiative-retrospectives
**Version:** 0.26.0

## Terms

| Term | Definition | Aliases | Used In |
|------|-----------|---------|---------|
| Retrospective | A written review of a finished run or initiative. It lists what to keep, what to change, and the actions that follow. | none | ravintio-zero |
| Run retrospective | A retrospective for one shipped feature run. Ship writes it after the build report. | none | ravintio-zero |
| Initiative retrospective | A retrospective across every step of a delivered initiative. I-E Delivery writes it before the PR to `main`. | post-initiative retrospective | ravintio-zero |
| Blameless | A rule that a cause names a gap in a process, check, standard, or tool. It never names a person or an agent. | none | ravintio-zero |
| Change | A step the next run takes. Each change becomes a backlog entry or a repo instruction that names its source retrospective. | none | ravintio-zero |
