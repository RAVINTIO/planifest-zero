**Skill:** [plan](../skills/ravintio-plan/SKILL.md)
**Feature:** 0000204-run-and-initiative-retrospectives
**Version:** 0.26.0

## In Scope

- Add the `ravintio-retrospective` skill with a run mode and an initiative mode, and a record template.
- Run the run mode at ship after the build report, and list the record in the report.
- Run the initiative mode at I-E Delivery after the archive and before the PR, and list the record in the PR body.
- Read the latest retrospectives at P0 discovery and at I-A Chart.
- Add a catalogue row. Update `component.yml`, the architecture overview, and the pipeline reference to 15 skills.
- Add tests.

## Out of Scope

- A script that gathers retrospective data or writes records.
- A ship or delivery block on a missing retrospective.
- Chart-time decisions from past stops, which backlog entry 0000186 covers.
