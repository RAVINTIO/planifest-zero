# Requirement: REQ-002 - attribution-check-script

**Skill:** [plan](../skills/ravintio-plan/SKILL.md)
**Feature:** 0000169-release-hygiene
**Source:** US-001 (backlog 0000166)
**Priority:** must-have

## User Story

As a maintainer, I see no AI attribution lines in any PR description, so that PRs follow the same rule as commits.

## Functional Requirements
- Today `ravintio-zero/hooks/commit-msg` Rule 1 matches `Co-Authored-By` lines naming an AI tool and phrases such as "generated by Claude". It does not match `Generated with [Claude Code]` or a `Claude-Session:` line. Nothing checks a PR body.
- Add `ravintio-zero/scripts/check-attribution.mjs`, a Node.js ESM script.
- The script reads the file path in its first argument. If no argument exists, it reads stdin.
- The script exits 1 when any line matches an attribution pattern. It exits 0 when no line matches.
- The script exits 2 on a usage error or when it cannot read the input.
- The patterns are every pattern in `commit-msg` Rule 1, plus the host lines: `Generated with [Claude Code]`, with or without a robot emoji, and `Claude-Session:` lines and claude.ai/code session links.
- On a match, the script prints only the line number and the rule name to stderr. It never prints the line text or the body.
- The script matches attribution lines, so prose that mentions the word "attribution" passes.
- The `commit-msg` hook gains the host-line patterns `Generated with \[?Claude Code` and `Claude-Session:` in Rule 1.

## Acceptance Criteria
- [ ] The script exits 1 for a file with each host line and for a file with each Rule 1 pattern. It exits 0 for a file with none, including prose that mentions the word "attribution". It exits 2 for a missing file or an unreadable input.
- [ ] On exit 1, stderr holds the line number and rule name, and neither stdout nor stderr holds any text from the input.
- [ ] The `commit-msg` hook rejects a message with a `Generated with [Claude Code]` line and a message with a `Claude-Session:` line.

## Dependencies
- REQ-001 names the host lines this script matches.
- REQ-003 runs this script in ship and CI.
