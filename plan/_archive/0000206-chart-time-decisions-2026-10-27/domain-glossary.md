# Domain Glossary - chart-time decisions

**Skill:** [plan](../skills/ravintio-plan/SKILL.md)
**Feature:** 0000206-chart-time-decisions
**Version:** 0.28.0

## Terms

| Term | Definition | Aliases | Used In |
|------|-----------|---------|---------|
| Pre-mortem | A Chart question about what would stop each step. Each likely fork becomes a row in the decisions table. | none | ravintio-zero |
| Decision row | One row in `## Decisions`. It names a fork, its pre-approved answer, and the bump effect. | none | ravintio-zero |
| Fallback | Scope that a step may add if its target is missed. A decision row lists it. | none | ravintio-zero |
| Baseline | A profile taken at Chart that shows where the cost of a performance target goes. | none | ravintio-zero |
| Criterion critic | A Chart check of each measurable criterion for drift, noise, and margin. | none | ravintio-zero |
